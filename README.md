# Hyderabad Goa Transport (HGT)

> Premium, minimalist corporate landing page for Hyderabad Goa Transport — specialized inter-state cargo and freight logistics connecting Telangana and coastal Goa.

---

## 🚛 Overview

Hyderabad Goa Transport operates a dedicated 720 km inter-state freight corridor between Hyderabad (Shamshabad / Gaganpahad) and Goa (Panaji / Vasco / Verna). This application is a high-performance, responsive single-page experience built with precision animation, strict visual restraint, and direct inquiry integration.

---

## ✨ Features & Architecture

- **Editorial Didone Design**: Clean white canvas (`#FFFFFF`) with Didone typography (`Bodoni Moda`) and modern sans-serif (`Plus Jakarta Sans`).
- **Synchronized Scroll Animation**:
  - Interactive hero section with a typewriter intro sequence.
  - Custom SVG cargo truck rolling right-to-left along a dedicated road line.
  - Wheels rotate strictly in place on their respective axles, perfectly scrubbed to user scroll via GSAP `ScrollTrigger`.
  - Bidirectional scrubbing: reverse scroll naturally reverses vehicle travel and wheel rotation.
- **Direct Freight Dispatch Integration**:
  - **Phone / Call Desk**: `+91 98493 02205`
  - **Email**: `Hyderabadgoa1977@gmail.com`
  - **WhatsApp**: Instant quote and booking chat link
  - **Terminal**: Gaganpahad, Shamshabad, Hyderabad, Telangana
- **Zero CLS & Responsive Layout**: Optimized across desktop, tablet, and mobile viewports (375px to 1440px+).

---

## 🛠 Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Animation**: GSAP (GreenSock) + GSAP ScrollTrigger
- **Styling**: Vanilla CSS with structured design tokens (zero utility bloat)
- **Linter / Tooling**: Oxlint + TypeScript compiler

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/ADARSHPATIL14/Hyderabad-Goa-Transpoart.git

# Navigate to project directory
cd Hyderabad-Goa-Transpoart

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Typecheck and build production bundle
npm run build

# Preview production build locally
npm run preview
```
